# Kenkos website

Next.js 14 (App Router) + TypeScript + Tailwind + Lucide.

    npm install
    npm run dev      # http://localhost:3000
    npm run build

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL` (and optionally `NEXT_PUBLIC_FORM_ENDPOINT`).

Edit content in `lib/`: contact.ts, jobs.ts, countries.ts, services.ts, guides.ts, faqs.ts, journey.ts, navigation.ts.
Images are in `public/images`. Privacy and Terms are drafts for legal review.
